CDN Simulator

PythonFlaskD3.jsDockerGunicorn
  • Built a full-stack CDN simulator in Python and Flask, modeling geolocation-based routing, edge caching, and failover across a network of server nodes.
  • Implemented Haversine great-circle distance calculations to automatically route each request to the nearest operational edge node or origin server.
  • Engineered an edge cache engine with LRU eviction and TTL expiration, distinguishing fast cache HITs (~18ms) from origin-fetched MISSes (~180ms).
  • Simulated real-world network conditions with configurable 5G/4G/3G speed profiles and randomized latency jitter.
  • Built failover resilience — toggling edge nodes online or offline in real time reroutes traffic to the next nearest available node.
  • Designed a dark, NOC-style dashboard with D3.js and TopoJSON world maps, rendering live curved request arcs and streaming request logs.
  • Made metrics thread-safe with Python's threading.Lock() and containerized the app with Docker and Gunicorn for production-style deployment.
